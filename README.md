# Predictive Maintenance using Slope Entropy

This repository contains the source code for the early fault detection of industrial bearings using a novel non-linear complexity estimator called **Slope Entropy**. The project has been designed with strict computational efficiency in mind to ensure its feasibility for deployment on resource-constrained Edge Computing platforms (e.g., Raspberry Pi).

## Requirements

The project relies on standard scientific libraries. To install the dependencies, you can use the provided requirements file:

```bash
pip install -r requirements.txt
```

*(Note: The primary dependencies are `numpy` for vectorized processing and `matplotlib` for plotting).*

## Execution Instructions

The main pipeline can be run with a single command. It will execute the data preprocessing, feature extraction, turning point detection, generate all the necessary figures, and output a time-stamped execution log.

```bash
python main.py
```

### Outputs generated by `main.py`:
- `processed_data/bearing1_hybrid_dataset.npz`: Compressed dataset to minimize I/O overhead.
- `latex/entropy_evolution.png`: Plot illustrating the Slope Entropy over time and the automatically detected turning point.
- `latex/computational_cost.png`: Execution time profile of the pipeline stages.
- `logs/execution_log_YYYYMMDD_HHMMSS.txt`: Text file with full traceability of the parameters used and the execution times.

## Key Results & Visualizations

### 1. Early Fault Detection (Slope Entropy Evolution)

![Slope Entropy Evolution over Time](latex/entropy_evolution.png)

* **Baseline vs. Degradation:** During initial operation (Records 0–41), Slope Entropy remains stable around $\approx 3.01$, representing high-complexity random friction noise characteristic of a healthy bearing.
* **Automated Turning Point Detection:** At **Record 42** (2004.02.17 08:02:39), the system flags an automatic turning point as entropy drops significantly below the statistical baseline ($> 3\sigma$)[cite: 4, 5]. This drop reflects the onset of a localized outer race defect, transitioning the signal into a more deterministic pattern long before total mechanical failure[cite: 1, 5, 7].
* **Key Advantage:** Unlike traditional time-domain metrics (e.g., RMS or Peak-to-Peak) which primarily spike during severe damage[cite: 5], Slope Entropy captures the subtle, non-linear dynamic shifts at early degradation stages[cite: 1, 5].

## Script Descriptions

The repository is modularized into the following scripts:

### 1. `main.py`
The orchestrator script. It unifies the entire execution pipeline. It calls the preprocessing module to build the dataset, loads the data into memory, iteratively computes the Slope Entropy for the 72 time-windows, and applies a statistical deviation criteria ($> 3\sigma$) to automatically detect the exact moment when the bearing began to degrade (Turning Point).

### 2. `prepare_dataset.py`
Handles the raw data acquisition and preprocessing. It reads the raw `.txt` files from the NASA IMS dataset using a periodic sampling strategy (1 out of every 8 files between February 15th and 18th). It extracts the data from Bearing 1 and consolidates everything into a highly optimized binary array (`.npz`). This avoids reading thousands of text files iteratively.

### 3. `slope_entropy.py`
The core mathematical algorithm. It implements the Slope Entropy estimation purely vectorized in NumPy (no slow Python loops) to ensure extreme performance. It translates physical amplitude differences into symbolic patterns based on decision thresholds ($\gamma$ and $\delta$), computing the final Shannon Entropy of the symbolic distribution.

### 4. `explore_data.py`
An exploratory script used in the initial phase of the project to understand the raw vibration signals. It calculates classical time-domain statistics (Root Mean Square, Peak-to-Peak, and Kurtosis) and plots the visual differences between a healthy signal and a degraded signal.

### 5. `comparative_analysis.py`
An analytical script used to extract and compare quantitative metrics across three defined stages of the bearing's life: Healthy, Transition (turning point), and Faulty. It prints out a comparative table used in the scientific report to highlight why Slope Entropy is superior or complementary to classical metrics.

### 6. `sensitivity_analysis.py`
A validation script used to perform the Parameter Sensitivity Analysis. It recalculates the entire temporal evolution by varying the primary threshold $\gamma \in \{0.5, 1.0, 1.5\}$. It demonstrates that the algorithmic detection of the turning point is robust and not overtly dependent on hardcoded parameter tuning. Generates the `parameter_sensitivity.png` plot.
